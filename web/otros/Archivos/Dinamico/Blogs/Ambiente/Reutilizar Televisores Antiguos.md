# Que hacer Teniendo una TV Antigua?

Muchas TVBox, Incluida la de Personal Flow F1 tienen una entrada atras de AV que es como un Auricular.

Comprando el Adaptador Jack-AVCompuesto puedes hacer que la vieja TV funcione con la TVBox
Puedes comprar aqui: [Accesorios para TVBox ↗️](#web/search.html#TVBox)



De esta manera usar apps como YouTube etc. (Las TVBox requieren WiFi)
