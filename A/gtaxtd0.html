¿Que Significa el Mensaje “Proveedor Externo”?

Esta web funciona como un Shopping, Se incluyen otros vendedores alineados a la politica de Cuidado Ambiental. Cada vendedor puede tener su propio metodo de pago, delivery y demas detalles.

Estos vendedores pueden no respetar estas reglas, se les insta y controla para garantizar el cumplimiento; quienes no lo hagan serán excluidos del catálogo.

Puedes Reportar a los Vendedores que no Siguen las Politicas de Mencionadas Aqui ⬇️ a traves de este Medio:

Requisitos

Queremos fomentar el consumo sostenible. Esta plataforma solo permite vendedores que cumplan criterios ambientales y de calidad.

Contaminación y materiales

Se prohíben productos y empaques que generen impacto ambiental evitable, incluyendo materiales de alto residuo, difícil reciclaje o baja durabilidad.

Plásticos

No se permite el uso de plásticos de un solo uso ni desperdicio innecesario en empaques, presentación o distribución.

Ejemplos

Diseño no reparable

Ejemplo dispositivos electronicos de baja reparabilidad y bootloader cerrado que imposibilite cualquier metodo para darle nueva vida.
Ejemplo productos de Apple, Nuevos Samsung, Nuevos Xiaomis etc. Los Usados se permiten para no dejarlos como chatarra…

Exclusividad de productos

Si ya existe un producto registrado (ej: “Torta de Chocolate Sin Lactosa”), no se permite otro igual. Pero si se permiten variantes como “Torta de Chocolate con Limon”
Se prioriza calidad, durabilidad y menor impacto ambiental.

Alimentos

Alimentos

Vegetariano

Si son alimentos deben cumplir la regla Vegetariana (no confundir con vegano ↗️)

  1. No carnes
  2. Informacion Nutricional
  3. Informacion de Alergenicos

No se permite carne, pero si huevo, leche, quesos, miel etc.

No platicos

De igual manera que demas productos, envolturas plasticas no estan permitidas si usted no se encargara del reciclaje.

Electronicos

Productos Sensibles

Productos de alto valor o riesgo (ej: teléfonos, notebooks, electrónica costosa) requieren validación previa del vendedor.

Es obligatorio aprobar un proceso de confiabilidad antes de publicar este tipo de productos.

Juegos y Apps

Proyectos de Codigo libre en Repositorios

  1. No debe contener codigo ofuscado
  2. El repositorio debe ser publico
  3. Si incluis scripts internos deberas Utilizar la carga correcta de core.js
  4. La entrada puede ser Descriptiva (y enlace al proyecto en algun lugar) o una simple redireccion (meta http-equiv=“refresh” content=“0; https://TuRepositorio”)

Simplemente solicita un PR con tus respectivos archivos en web/Dinamico/Apps|Juegos

Una imagen y un .md, ambos con el mismo nombre. Se hara una revision y si no es Mal Intencionado ↗️ se aprobara.
